Read the audit trail

  1. An administrator opens the Audit trail; the list renders with actor, action, and record columns.
  2. An administrator filters the trail by actor uat-admin; only that actor's entries remain.
  3. An administrator opens the configuration audit at Configuration audit; configuration-scoped entries render actor and action.
  4. An administrator opens one export entry; the detail names the actor, the action, and the exported object.

Not in this release. Token issue, scoping, and revocation are not in this release.
