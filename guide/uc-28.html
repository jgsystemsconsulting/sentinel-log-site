Guide

Unpack, configuration edit, install script, smoke test, upgrade, backup, and restore stay in the release bundle and are not repeated here. See deploy/customer/install.sh and docs/operations/admin-guide.md. Do not paste shell commands on this page.

  1. An administrator opens the diagnostics export at /diagnostics/; browser downloads a JSON attachment whose payload carries product version, health status, and configuration with secrets removed.
  2. An administrator reads the downloaded payload and decides whether to send it to the supplier.
  3. An administrator reads the AI provider allowlist in the downloaded payload; the delivered configuration holds none, so every product function works with AI disabled.
