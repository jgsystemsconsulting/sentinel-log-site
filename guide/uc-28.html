UC-28: Diagnostics export on a supplier-free install

Unpack, configuration edit, install script, smoke test, upgrade, backup, and restore stay in the release bundle and are not repeated here. See deploy/customer/install.sh and docs/operations/admin-guide.md. Do not paste shell commands on this page.

Main flow

  1. administrator opens the diagnostics export at /diagnostics/; browser downloads a JSON attachment whose payload carries product version, health status, and configuration with secrets removed (req-120).
  2. administrator reads the downloaded payload and decides whether to send it to the supplier (req-120).
  3. administrator reads the AI provider allowlist in the downloaded payload; the delivered configuration holds none, so every product function works with AI disabled (req-121).
