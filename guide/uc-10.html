UC-10: Filter, group, sort, colour. Actor: All

Main flow

  1. viewer opens the register with no query; UAT-0001 renders and the count line states totals with archived excluded (req-26).
  2. viewer filters status open; UAT-0001 stays listed and the applied filter chip renders (req-26).
  3. viewer searches q UAT-0001; only the matching record lists and the count line states one shown (req-103).
  4. viewer groups by residual risk; one band header per category states its hazard count (req-26).
  5. viewer sorts residual score high first; the sort control shows the active rule (req-26).
  6. every risk cell renders the colour rule chip with written category and icon, never colour alone (req-27).
