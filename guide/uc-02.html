Configure a project

  1. An administrator opens Settings. The configuration lists are: analysis types, status labels, custom fields, controlled lists, identifier schemes, risk criteria versions, colour rules, dashboard panels, and ranking rule.
  2. An administrator opens the Meridian risk criteria version; the seeded scales, categories, and matrix cells render and prior versions are retained read-only.
  3. An administrator adds a controlled-list value in Settings; the new value appears in the list changelist.
  4. An administrator adds a status label on the Meridian project mapped to a core status; the label appears on the project status label changelist.
  5. An administrator opens the Configuration package; the export and import panels render.
  6. An administrator submits the export form and the browser downloads a JSON package whose header format is sentinel-log-configuration and whose families include criteria_versions, controlled_lists, status_labels, custom_fields, colour_rules, and dashboard_panels.
  7. An administrator uploads the downloaded file to the import form; on a register carrying risk assessments Sentinel Log refuses with the populated-system message and writes nothing, and on an empty installation it re-imports and reports Import applied with the applied families named.
  8. An administrator opens the Configuration audit; the export session is recorded with actor and action.
