# Sentinel Log site

Static marketing site for Sentinel Log, a self-hosted hazard log and safety traceability tool by JG Systems Consulting Ltd.

Live: https://jgsystemsconsulting.github.io/sentinel-log-site/

Plain HTML, CSS and JavaScript. No build step, no third-party requests. Fonts are self-hosted under the SIL Open Font License (see `fonts/`). Film credits: `film/out/CREDITS.txt`.
